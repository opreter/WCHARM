# 時計／三ヵ月カレンダー　"Charmy for Windows"

  前月、当月、来月の三ヵ月を表示する３ヶ月カレンダーです。  
  ついでに、現在の日付、時刻も表示します。  
  タイマーやアラームもあります。  
  また、簡易的なランチャーとしても使えます。  
　  
## kwsk
- カレンダー
  - 前月、当月、来月の三ヵ月のカレンダーアプリです。  
  - 和暦表示もあったりします。  
  - 内閣府のWebページ（ https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html ）
    にある祝日のcsvファイルを読み込ませることで、祝日の表示も行えます。  
  - 今日の日付をマークはしますが、予定などの表示、マークはしません。  
　  
- 時計
  - 現在の日付、時刻をメニューバーの下に表示します。  
  - 分単位のタイマーもあります。設定した時間経過後、ダイアログを表示します。
  (音は鳴りません)  
  - 時刻を指定してアラームを出すこともできます。(保存はできません)    
  - あらかじめ設定しておくことで最大32個までアラームを設定できます。  
　  
- ランチャー
  - 簡易的なアプリランチャーとしての機能があります。  
    メニューの　Item に登録され、メニューからから実行できます。  
  - ウィンドウ内にエクスプローラからのファイルをドロップすることで、
    そのファイルを開くアプリを選択できます。  
  - Charmyの起動に連動してアプリを実行することができます。  
  - 起動するアプリは指定したフォルダにショートカット等を置くことで登録できます。  
　  
- システム制御
  - Option のメニューからシステムのログオフ、再起動、シャットダウンを行うことができます。  
　  
- 設定
  - レジストリはいっさい使用しません。かわりに旧来のiniファイルを使用します。
  - iniファイルは、  
    起動時のカレントフォルダ →  
    環境変数「CHARM」の示すフォルダ →  
    環境変数「HOME」の示すフォルダ →  
    ドキュメントフォルダ →  
    実行ファイルのあるフォルダ、  
    の順序で探します。
  - iniファイルが無い場合は実行ファイルのあるフォルダに作成します。
　  
- その他
  - 残念ですが、表示フォントは固定です、あしからず。  
  - あえて、固定サイズのウィンドウアプリとして動作します。  
    タスクトレイには引っ込みません。不必要なときには他のウィンドウに隠れ、
    必要なときにタスクバーをクリックすることで浮上する、
    という使い方を想定しています。  
　  
　  
## 以下余談
　もともとは Windows 3.1 の時代に作成したものです。  
　もっと遡れば、PC-9801で仕事をしていた際に作成した常駐型時計表示ソフトからに
なります。  
　Windows 3.1当時、このテのアプリは壁紙に描く物だとか、簡易的なスケジューラとして使える
物だとか、ちょっと探せばいろいろありました。  
　しかし、壁紙に描くタイプの物は、ウィンドウを開くと，当然，壁紙が見えなくなりますし、
たいていひと月分しか表示できません。  
　前月からの流れや来月への流れを考えるときに三ヵ月のカレンダーが欲しい、
と思っていたので作成しました。
